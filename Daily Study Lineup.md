# Daily Study Lineup

> [!tip] How to use this page
> Each day has **three 90-minute blocks and one 45-minute block**. If time is short, protect Blocks 1–3 and move Block 4 to the next day. Never skip the exam-morning block.
>
> Follow [[Learning Workflow]] inside every block. A block is complete only when you have written something: a recall sheet, a solved question, a diagram, or a corrected error.
