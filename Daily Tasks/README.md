# Daily Tasks

Reusable templates for daily study planning. Duplicate a template into this folder and rename it with the date, for example `2026-11-22.md`.

- [[Daily Tasks/Daily Study Template|Daily Study Template]] — normal study day.
- [[Daily Tasks/Revision Day Template|Revision Day Template]] — revision-focused day.
- [[Daily Tasks/Exam Eve Template|Exam Eve Template]] — the day before an exam.

The day-by-day plan is in [[Daily Study Lineup]]. Use these templates when you need a separate daily note; adjust the number and length of sessions to your actual availability.
