# Daily Tasks

Reusable templates for daily study planning. Duplicate a template into this folder and rename it with the date, for example `2026-11-22.md`.

- [Daily Study Template](/Daily Tasks/Daily Study Template.md) — normal study day.
- [Revision Day Template](/Daily Tasks/Revision Day Template.md) — revision-focused day.
- [Exam Eve Template](/Daily Tasks/Exam Eve Template.md) — the day before an exam.

The day-by-day plan is in [Daily Study Lineup](/Daily Study Lineup.md). Use these templates when you need a separate daily note; adjust the number and length of sessions to your actual availability.
