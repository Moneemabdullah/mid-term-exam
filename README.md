## How to use this vault

1. Open this folder as a vault in Obsidian.
2. Start with the subject hub, not with the PDF folder.
3. Study one topic per block using [[Learning Workflow]].
4. Follow [[Daily Study Lineup]]; move missed work to the next day's Block 4.
5. Update [[Progress Tracker]] only after actual study, not after reading this page.

## Repository notes

- Source PDFs, PPTX files, and the scanned notebook are kept for offline study.
